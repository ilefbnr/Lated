# Supervisor Demo

This folder contains a standalone supervisor-facing demo for the LateD platform.

It was created without modifying the existing backend or frontend code.

## Files

- `index.html`: the demo entry point
- `styles.css`: standalone styling
- `app.js`: mock data and interactions

## How to use it

1. Open `supervisor-demo/index.html` in a browser.
2. Use the left-side module tabs to walk through each platform feature.
3. Click `Play attack story` if you want the page to guide the presentation order automatically.

## What it covers

- Network discovery
- Discovery baseline topology graph
- Multi-source ingestion
- Temporal graph modeling
- TGNN-based lateral movement detection
- Reconnaissance detection
- Suspicion fusion
- Attack path reconstruction
- Overview, alerts, attack graph, timeline, hosts, and flows views
- Admin threshold and model inventory surfaces

## Notes

- All values are mock data prepared for demonstration.
- The language and structure align with the actual repository documentation and page layout.
- Because it is static, it is safe to present without depending on backend services.
